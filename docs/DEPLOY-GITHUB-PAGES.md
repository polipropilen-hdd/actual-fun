# Публикация Actual Fun на GitHub Pages

Конструктор — полностью статический сайт (без сервера и сборки), поэтому GitHub Pages подходит идеально.

## Шаг 1. Создать репозиторий

```bash
git init -b main            # если ещё не инициализирован
git remote add origin https://github.com/<ВАШ_ЛОГИН>/actual-fun.git
git add .
git commit -m "Actual Fun: каркас конструктора"
git push -u origin main
```

## Шаг 2. Включить Pages

1. Откройте репозиторий на GitHub → **Settings** (вверху справа).
2. В левом меню → **Pages**.
3. **Source** → `Deploy from a branch`.
4. **Branch** → `main`, папка → `/ (root)`, нажмите **Save**.

GitHub соберёт сайт за ~1 минуту. Адрес будет:

```
https://<ВАШ_ЛОГИН>.github.io/actual-fun/
```

## Шаг 3. Открыть демо

Сейчас в репозитории готово core-демо каркаса (реестр типов, форма из схемы, загрузка JSON с валидацией, живые блоки-игроки). Прямые ссылки:

| Что | Ссылка |
|---|---|
| Core-демо | `https://<ВАШ_ЛОГИН>.github.io/actual-fun/demo-core.html` |

Полноценный конструктор появится по адресу `https://<ВАШ_ЛОГИН>.github.io/actual-fun/`
(`index.html`) на следующем этапе разработки.

## Возможные проблемы

- **404 сразу после Save.** Pages обновляется 1–2 минуты; сделайте hard-refresh (Ctrl+Shift+R).
- **Страница открывается, но JS молчит.** Откройте консоль браузера (F12) — проверьте, что все файлы доехали (иногда помогает повторный push).
- **Репозиторий приватный.** На бесплатном тарифе Pages для приватных репозиториев нужен Pro. Сделайте репозиторий public (Settings → Danger Zone → Change visibility).
- **Другая папка.** Если захотите хранить конструктор не в корне, укажите эту папку в поле Branch/папка вместо `/ (root)`.

## Локальный запуск (для разработки)

ES-модули не работают по протоколу `file://`, нужен любой локальный сервер:

```bash
python3 -m http.server 8080
# открыть http://localhost:8080/demo-core.html
```

Финальные экспортированные упражнения будут работать и без сервера (двойной клик по `.html`) — это ограничение только для исходников конструктора.
